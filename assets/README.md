# Screenshots

Drop the images here, then declare them in `screenshots.json` at the repository
root (1–8 relative paths, no leading `/`, no `..`). Without that file the
marketplace extracts images from `README.md` instead.

| File | What to capture |
| --- | --- |
| `01-projects.png` | The right sidebar with two or three project groups, one running and one stopped |
| `02-actions.png` | A row under the pointer, so the actions replace its status cell |
| `03-logs.png` | A service log tab, with the replay-size control visible |

PNG, light or dark theme, roughly 1200–1600px wide is plenty — the storefront
scales them.
